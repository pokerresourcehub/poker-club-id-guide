Start with the basics

Club IDs help players find or request access to a specific private community inside an app. The ID should be checked against the club name, app, support process, rules, and source that shared it.

What this guide covers

This owned resource explains club IDs, referral IDs, verification steps, and app-specific notes for PokerBros and ClubGG users.
